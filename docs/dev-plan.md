# SAI2 插件开发计划（一期：液化工具）

- 状态：Phase 0 进行中

## 阶段总览

| 阶段 | 内容 | 产出物 | 出口标准 | 预估 |
|---|---|---|---|---|
| **P0 逆向打底** | 图层结构、坐标变换、重绘触发、撤销栈 | `docs/sai2-offsets.md` 补齐 §1–§4 | 最小链路所需全部地址/偏移确认 | 2–3 周 |

## P1 最小链路

- [ ] **injector.exe**：CreateRemoteThread + LoadLibraryW；开发期支持热重载
- [ ] **DLL 骨架**：DllMain 安全（不持锁），独立工作线程
- [ ] **特征码扫描器**：不依赖固定 RVA，按指令序列定位（0x58 描述对象字段、分配器、重绘函数）
- [ ] **读像素**：选中图层 → 描述对象 +0x18 → BGRA 缓冲 → 导出 PNG 验证正确性
- [ ] **写回 + 重绘**：修改像素 → 触发 0.5 的重绘路径 → SAI 画面更新
- [ ] **稳定性**：SAI 继续作画、保存 .sai2、重开文件结果正确（PRD 2.8 相关项）

## P2 液化引擎（与 P1 并行）

- [ ] 稠密位移场 float2，与图层等尺寸（PRD §4）
- [ ] 五种笔刷：推拉（MLS 移动最小二乘，CSP/PS 同款手感）、膨胀、收缩、平滑、重建
- [ ] 参数：大小/力度/浓度（速率）/硬度羽化；`[` `]` 调大小
- [ ] 双线性重采样预览渲染；确定时一次重采样
- [ ] 性能：分块 + SIMD（SSE2/AVX2）；10MP ≥30fps 基准
- [ ] 单测：合成图变形回归测试（网格图/同心圆基准图）
