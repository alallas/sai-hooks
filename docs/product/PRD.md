# SAI 插件 PRD（产品需求文档）

- 版本：v0.2（产品决策已确认）
- 目标软件：PaintTool SAI Ver.2（64bit）Preview 2024.02.22（仅此一个版本，不承诺兼容其他版本）
- 技术形态：C++ DLL 注入 + 自绘悬浮窗口（ImGui）
- 状态：已确认，可进入开发

---

## 1. 背景与目标

SAI2 画笔手感优秀，但长期缺少调色与变形类工具：无液化、无曲线/色阶/渐变映射等调整工具、笔刷管理依赖手工搬运文件。本插件以 DLL 注入方式为 SAI2 补充这些能力。

**一期目标（本 PRD 确认范围）**：液化工具可用、稳定。
**二期及以后**：调整类工具、笔刷导入、辅助功能（见第 6 节，不在本期验收范围）。

## 2. 一期范围：液化工具（仿 CSP）

### 2.1 功能描述

对当前选中图层的像素进行笔刷式变形，交互与手感对标 Clip Studio Paint 的液化。

### 2.2 工作方式

1. 快捷键 `Ctrl+Shift+X` 呼出液化悬浮窗（沿用 PS 液化的肌肉记忆），可在配置文件 `sai_hooks.ini` 中修改。
2. 插件快照当前图层像素，在**插件悬浮窗内**显示和操作；SAI 画布在液化期间保持原样。
3. 悬浮窗支持缩放/平移，视角可与 SAI 画布对齐。
4. 用户用笔刷在悬浮窗内涂抹变形，实时预览。
5. **确定**：按位移场重采样结果并写回 SAI 图层，SAI 显示变形后的图。
6. **取消**：丢弃全部修改，SAI 图层不变。

### 2.3 液化笔刷种类（对标 CSP）

| 笔刷 | 行为 |
|---|---|
| 推拉 Push | 沿笔刷移动方向带动像素（MLS 变形，CSP/PS 同类手感） |
| 膨胀 Bloat | 像素向笔刷中心外推 |
| 收缩 Pinch | 像素向笔刷中心内聚 |
| 平滑 Smooth | 柔化已产生的变形 |
| 重建 Restore | 将涂抹区域逐步恢复为原始图像 |

### 2.4 参数

笔刷大小、笔刷力度、浓度（变形速率）、羽化/硬度。参数交互方式与 CSP 一致，笔刷大小支持 `[` `]` 快捷键调节。

### 2.5 保护功能

冻结蒙版：涂抹区域标记为保护，任何变形笔刷对其无效；支持擦除冻结。

### 2.6 撤销与重置

- 液化会话内支持**按笔撤销**（Ctrl+Z / 面板按钮）：一次起笔到抬笔为一个撤销单位，与主流绘画软件习惯一致；重做 Ctrl+Y。
- 面板提供**一键全部重置**：清空位移场与冻结蒙版，回到会话开始时的原始图像（需二次确认或长按，防误触）。
- 确定写回后，由 SAI 自身撤销栈接管（是否成功接入 SAI 撤销栈取决于逆向结果，见风险 R1）。

### 2.7 确认与取消交互

- 面板"确定 / 取消"按钮 + `Enter` 确定 + `Esc` 取消，与 CSP 一致。
- 取消时可二次确认（若本次会话已有变形操作），防止误触丢失工作。

### 2.8 验收标准

- 在 2024.02.22 x64 版 SAI2 上：呼出 → 变形 → 确定写回，全流程不崩溃、结果正确。
- 取消后 SAI 图层无任何变化。
- 冻结区域在任意笔刷下不变形。
- 按笔撤销、一键重置可用；`Enter`/`Esc` 快捷键符合 2.7 节定义。
- 写回后 SAI 可正常继续作画、保存文件；重新打开文件结果为变形后的图。
- 撤销（插件内会话撤销）可用。

## 3. 非功能性要求

- 性能：1000 万像素的图层上，笔刷涂抹预览帧率 ≥ 30fps（开发机基准）。
- 稳定性：写回像素不导致 SAI 崩溃、花屏或撤销栈损坏。
- 兼容性：以特征码扫描定位数据结构，SAI2 同版本系列小更新尽量不失效。

## 4. 技术方案摘要

- `sai_hooks.dll`：被注入 SAI2 进程的插件本体，内嵌 ImGui 绘制悬浮窗。
- `injector.exe`：开发/发布用的注入器。
- 液化引擎：维护与图层等大的稠密位移场（float×2），笔刷累积位移，双线性重采样渲染预览；确定时一次重采样写回。
- 依赖前置逆向成果：图层结构（像素缓冲区、尺寸、选中状态）、画布↔像素坐标变换、写回后触发重绘的方式。逆向结论记录于 `docs/sai2-offsets.md`。

## 5. 一期不做（Out of Scope）

- SAI 画布内的 overlay 实时预览（仅悬浮窗预览）。
- 非破坏性/可反复调整的液化（写回即烘焙）。
- 液化作用域限定单图层；不做"跨图层液化"。
- 除液化外的全部功能（见第 6 节）。

## 6. 二期及以后规划（仅罗列，不进本期验收）

按实现依赖排序：

1. **调整类工具**（原位悬浮窗调整，确定后烘焙）：曲线、色阶、渐变映射、色彩平衡、亮度/对比度、添加杂色。
2. **可编辑描边工具**（仿 CSP）：矢量描边数据随层保存，合层后仍可调整粗细颜色。
3. **笔刷导入**：.abr/.sut 一键转换导入，含笔尖与纹理。
4. **辅助功能**：
   - 吸管/选择工具忽略锁定图层；
   - 按住空格 + 数位笔平移图层面板；
   - 图层一键填充前景色。
5. **贝塞尔钢笔工具**：路径绘制、橡皮带、Enter 转选区。
6. **笔刷面板拖拽排序**：优先以自绘悬浮笔刷管理面板实现，不改 SAI 原生面板。

## 7. 已确认的产品决策

原待确认问题已与用户确认，按以下决策执行：

1. **液化快捷键**：`Ctrl+Shift+X`（对齐 PS 液化肌肉记忆），写入 `sai_hooks.ini` 可配置。
2. **撤销粒度**：按笔撤销（一笔 = 一次起笔到抬笔），支持撤销/重做。
3. **冻结蒙版**：一期必需，随液化一同交付。
4. **作用图层**：一期仅当前选中单图层，不做跨图层。
5. **一键重置**：提供，带防误触（二次确认或长按）。
6. **确认/取消**：面板按钮 + `Enter` 确定 / `Esc` 取消；取消在有变形操作时二次确认。
7. **二期优先级**：维持第 6 节排序；可编辑描边工作量大，接受排在调整类工具之后。
8. **版本范围**：仅支持 SAI2 2024.02.22（64bit）单一版本，不承诺兼容其他版本。

## 8. 风险

| 编号 | 风险 | 影响 | 应对 |
|---|---|---|---|
| R1 | 像素写回后 SAI 撤销栈/缓存不一致导致崩溃或花屏 | 高 | 逆向撤销栈结构接入，或写回前提示"此操作不可撤销"；最坏情况一期接受写回后不可撤销 |
| R2 | SAI 小版本更新导致结构偏移失效 | 中 | 特征码扫描 + 单一目标版本 |
| R3 | 逆向阶段工作量超出预期（图层结构难定位） | 中 | 先打通"读像素→写回"最小链路再扩展功能 |
| R4 | SAI 渲染管线挂钩方式不明（D3D/GDI） | 低 | 备选方案：插件独立透明悬浮窗，不挂钩 SAI 渲染 |
