# 踩坑记录（开发 sai-hooks 过程中踩过的坑）

每条坑记录：现象 → 根因 → 解法。新加入的开发者/未来的自己，请先读这篇再动手。

---

## 一、SAI 线程与安全

### 坑 1：外部线程直接调 SAI 内部函数，必崩
- **现象**：从插件自己的线程调 SAI 的画布/面板函数，SAI 随机崩溃。
- **根因**：SAI 是 Delphi 单线程程序，数据结构无锁。外部线程读时 SAI 可能正在改，读到一半的数据。
- **解法**：一切 SAI 内存操作走 `SendMessage` 到子类化的 SAI 主窗，在 SAI 的 UI 线程里执行。这条是铁律，没有例外。

### 坑 2：FUN_140022ab0 / FUN_140036770 以为是画布刷新，实际是面板刷新
- **现象**：写回像素后调这俩函数想刷新画布，SAI 崩溃。
- **根因**：这俩是**面板**刷新函数，非 UI 线程调用直接崩（2026-11-03 实证）。
- **解法**：画布刷新用 `FUN_140020ed0 / FUN_140022920` + `RedrawWindow`（见坑 5）。

### 坑 3：写回中途崩了，整个 SAI 陪葬
- **现象**：写回逻辑有 bug 时（如用户恰好在写回瞬间删图层），SAI 直接闪退，用户画的画全没了。
- **解法**：两层保险。
  1. 所有 SAI 指针先过 `plausible()` 校验（检查是不是像合法指针）。
  2. 写回包在 `setjmp/longjmp` 外壳里 + VEH（异常观察员）：写回前插旗子，一旦内存错误，异常观察员把执行拽回旗子处，本次写回失败但 SAI 进程活着。

## 二、视图刷新

### 坑 4：点「确定」后 SAI 画布不更新，要手动缩放才看到液化结果
- **现象**：写回明明成功了，画布上却是旧图；缩放一下画布才刷新。
- **根因**：少调了刷新链上的一环。
- **解法**：刷新三件套，缺一不可：
  1. `FUN_140020ed0`
  2. `FUN_140022920`
  3. `FUN_1401a6510(app, 0x10)` ← 就缺这个
  再加 `RedrawWindow(RDW_ALLCHILDREN | UPDATENOW)`。

### 坑 5：只写「有内容的瓦片」导致液化凸起被裁剪
- **现象**：液化把线条往空白处推（凸出原图层边界），确定后凸起部分被裁掉。
- **根因**：写回时跳过「没有原始内容」的瓦片。但位移场把像素推到了这些瓦片里，跳过 = 丢弃。
- **解法**：写回逐瓦片对比「变形结果 vs 原始快照」，有差异就写，不管原来有没有内容。

## 三、冻结功能

### 坑 6：冻结笔刷只能冻住「一个圆圈」
- **现象**：用冻结笔刷涂抹，只留下孤零零一个圆，涂过的轨迹冻不住。
- **根因**：`psFreeze` 着色器是全屏替换写入，每 dab 一次就把整张冻结图重置为 0，只保留最后那个圆（`v = inside` 在圆外写 0）。
- **解法**：冻结 = 叠加（`max(旧值, 本次)`）；解冻 = 局部擦除（`旧值 × (1 - 覆盖区)`）。涂抹轨迹本身是每 1px 一 dab，不用改。

## 四、窗口与界面

### 坑 7：SAI 把液化窗口藏起来
- **现象**：液化窗口消失，或被 SAI 的面板布局压在底下。
- **根因**：液化窗是 SAI 主窗的 WS_CHILD，SAI 的面板管理器会把不认识的儿子压到 Z 序底部。
- **解法**：每 2 秒定时器调 `SetWindowPos(HWND_TOP)` 把液化按钮和窗口重新置顶。

### 坑 8：液化窗默认宽度不够，画布盖住参数面板
- **现象**：窗口默认宽度按「画布宽 + 330」算，参数面板被挤出可视区或盖住。
- **解法**：默认宽度改为「画布宽 + 480」。另外窗口被压窄时，面板位置要动态回收进可视区（`GetClientRect` 实测宽度，不够就往左挪）。

### 坑 9：SAI 客户区尺寸「退化」时算出负数窗口
- **现象**：CreateSwapChain 报 `hr=80070057`，日志显示 `winW=282 winH=-16`。
- **根因**：SAI 主窗正处于尺寸过渡态（最小化/还原瞬间），`GetClientRect` 拿到退化值，窗口高度算出 -16。
- **解法**：客户区尺寸小于阈值（320×240）时不采纳其约束，用默认下限（700×500）。

### 坑 10：ImGui 滑条的 label 在窄面板里整个消失
- **现象**：参数滑条只剩一根条，文字标签全没。
- **根因**：`SliderInt("大小（笔刷直径）", ...)` 的 label 渲染机制在面板窄时被挤没。
- **解法**：改成 `Text("大小(笔刷直径):")` + `SameLine()` + `SliderInt("##id", ...)`。Text 独立渲染，百分百显示。顺带：全角括号（）：在 ImGui 默认中文字体里有缺字风险，标签统一用半角。

### 坑 11：SAI 的对话框是「自绘」的，程序点不了
- **现象**：用 `PostMessage` 模拟点击「强制退出的工程」「恢复文件」对话框，完全无效。
- **根因**：SAI 对话框（sflRootWindow 类）完全自绘，不响应标准消息。
- **解法**：`sai_boot.py` 用「附加输入队列 + SetForegroundWindow + 真实鼠标点击」；或者干脆启动前删掉 SAI 的自动恢复文件。批量杀 SAI 进程后必然弹「强制退出的工程」，部署脚本里已处理。

## 五、构建与部署

### 坑 12：杀毒软件吃掉 injector.exe
- **现象**：部署时报「系统找不到指定的文件」，`bin/injector.exe` 不见了。
- **根因**：杀软把注入器当病毒删了（DLL 注入是病毒常用技术，误报正常）。
- **解法**：重编注入器：`x86_64-w64-mingw32-g++.exe -O2 -static -std=c++11 -municode -o bin/injector.exe src/injector/injector.cpp`。长期方案：给杀软加白名单。

### 坑 13：链接 sai_hooks.dll 报 Permission denied
- **现象**：`python tools/build.py` 最后链接失败。
- **根因**：SAI 正在运行，占着 `bin/sai_hooks.dll`。
- **解法**：正常，不用管。构建脚本自动改产到 `bin/try/sai_hooks_fresh<N>.dll`（N 递增），部署时手动 cp 覆盖。先杀 SAI 再链接 bin/ 也行。

### 坑 14：Ctrl+Shift+X 热键注册失败 err=1409
- **现象**：日志报 `RegisterHotKey 失败 err=1409`。
- **根因**：别的软件占了这个热键。
- **解法**：DLL 已带 3 秒自动重试，等对方软件关掉会自动注册上。想换热键改 `bin/sai_hooks.ini`。

### 坑 15：MinGW 编译的 DLL 字符串里的中文变 ?? 或乱码
- **现象**：界面中文正常（ImGui 字体从系统 msyh.ttc 加载），但 `logf` 写日志的中文乱码。
- **解法**：源文件统一 UTF-8；日志查看用支持 UTF-8 的编辑器。Git Bash 的 `tail` 直接看会是 GBK 混 UTF-8，属正常。

### 坑 16：VS2026 路线走不通
- **现象**：`build.bat`（VC 路线）报 vcvars64 语法错误、cl 找不到 windows.h。
- **根因**：VS2026 没装 Windows SDK。
- **解法**：主构建链用 MinGW-w64（`tools/build/build.py`），零 SDK 依赖。VC 脚本已归档到 `artifacts/`。

## 六、流程与工具

### 坑 17：一上来就下载了 874MB 的 Ghidra，结果全程没用上
- **现象**：任务初期下载 Ghidra 准备静态分析，最后全程用 REA（更轻量的逆向工具）完成。
- **教训**：选工具前先花 10 分钟评估轻量替代方案。重工具（Ghidra/IDA）适合没头绪时，有明确目标（找偏移、看调用链）时 REA 这类工具更快。

### 坑 18：装完 MinGW 忘了删安装包
- **现象**：`winlibs.zip`（276MB）在 D:\tools 躺了好几天。
- **教训**：装完工具立刻删安装介质，或装的时候就下到临时目录。

### 坑 19：bin/try/ 堆了 50+ 个历史 DLL 版本
- **现象**：每次构建产一个新文件名，从 fresh2 到 fresh55，从来没人删。
- **解法**：现在只留最近 5 个在 `bin/try/`，其余归档 `artifacts/bin-history/`。以后确认验收通过后可以大胆清旧的。

## 七、验收方法（怎么证明没踩坑）

每次改动后，按这个顺序验一遍：

1. `head -6 %TEMP%\sai_hooks_log_<pid>.txt` 确认「热键已注册」
2. SAI 里画几笔 → 点「液化」按钮（或 Ctrl+Shift+X）→ 推拉几笔 → 确定
3. 看画布**立刻**更新（不用缩放）
4. SAI 里 Ctrl+Z 撤销液化、Ctrl+Y 重做，各一次
5. 无头自检：`python tools/deploy/sai_send.py <pid> 98`

**注意**：不要总在用户办公时把插件窗口唤到顶层截图——用户提过意见。验证优先看日志（`%TEMP%\sai_hooks_log_*.txt`）和无头自检。
